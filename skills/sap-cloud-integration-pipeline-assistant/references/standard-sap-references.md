## Beginner onboarding

Recommend a development/trial tenant, downloaded samples, Postman setup, standard package deployment, credential alias, helper flows, stage mapping when applicable, package import, Partner Directory setup, test invocation, and message monitoring. Never recommend deploying unreviewed sample content or sample credentials to production.
